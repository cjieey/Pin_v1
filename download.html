Questions

Android warned me about this app. Is that normal?

Yes. Pin. is not on the Google Play Store yet, so Google Play Protect may ask you to scan it or show a warning. Choose "More details", then "Install anyway". You can compare the file with the SHA-256 checksum on this page to make sure it has not been changed.

Google Drive says it can't scan the file. Is that a problem?

No. Google Drive shows that message for every file over 25 MB, because it only virus-scans smaller files. Tap "Download anyway" to continue.

Is there an iPhone version?

Not yet. This early version is for Android phones running Android 7.0 or newer.

How do I update to a newer version?

Download the newest APK from this page and open it. If Android says the app cannot be updated, uninstall Pin. first, then install the new file.

Does Pin. need the internet?

Only for downloading fonts and for one-tap background removal. Everything else works offline.
